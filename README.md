# My Own Personal STRIPS Solver
My initial goal with this library was to make a PDDL Solver for use in Video Games, but after some deliberation I decided that I should initially make a STRIPS solver, and then in a future, alternate repository, work on a PDDL Based Solver for use in Video Games. This comes from the fact that, although I want the expressiveness of a PDDL Based AI, it also represents a challenge to balance the ease of writing in STRIPS with the extensibility of PDDL, and so for most use cases, STRIPS is most likely 'enough'. That said, it is a problem I wish to tackle in the future.
